# 第三方数据来源与授权

这份文件记录仓库里**不是我们自己写**的数据资产，以及它们的授权。
新增内容数据时必须在这里登记 —— 否则以后没人说得清哪些数据能不能商用。

> 原则：**优先用能确认授权的数据；授权说不清的一律不用**，哪怕它更好用。
> 下面每一条都注明了核实方式。

---

## 语文 / 汉字（`public/cn/data/`）

由 `tools/cn/gen_chars.py` 生成（3500 常用字，每字带拼音/笔画/部首/释义/组词）。

| 用途 | 来源 | 授权 | 体积 |
|---|---|---|---|
| **字频顺序**（决定哪些字更常用、怎么分级） | [`forfudan/chinese-characters-frequency`](https://github.com/forfudan/chinese-characters-frequency) 的《六億知乎語料通規漢字字頻表》 | **Apache-2.0** ✅ 可商用 | 380 KB CSV |
| **拼音 / 笔画 / 部首 / 释义** | [`pwxcoo/chinese-xinhua`](https://github.com/pwxcoo/chinese-xinhua) 的 `data/word.json` | **MIT** ✅ | 27 MB（只取需要的字段） |
| **组词** | [`fxsjy/jieba`](https://github.com/fxsjy/jieba) 的 `jieba/dict.txt` | **MIT** ✅ | 5 MB，34.9 万词带词频 |

### ⚠️ 一个踩过的坑：组词**不能**用 chinese-xinhua 的 `ci.json`

同一个仓库里的 `data/ci.json` 有 26 万条，看着像"现成的词表"，**其实是一部古汉语词典**：

- 有「这的」「了的」「到的」「学人」这种**根本不是词**的条目（而且都带释义）
- 有「花国」这样的条目，释义是「旧指妓女行中」
- **却没有**「大人」「马上」「学校」「朋友」「老师」这些最日常的词

拿它当组词，孩子会在字表里学到古文，甚至是不当词汇。**实测踩过，已换掉。**

### 不雅词黑名单

`gen_chars.py` 里有一份 `BLOCK_SUBSTR`。为什么必须有：jieba 的词表是从真实语料统计的，
**里面什么都有** —— 实测「妈」的词频最高组词是「**他妈的**」。

黑名单目前挡掉 **427 个词**，包括 `他妈的` / `做爱` / `全裸图` / `上吊自杀` / `乳腺癌` / `切腹自杀` 等。
每次重新生成都会把被挡的词打印出来，方便人工过一眼。

代价是会误杀少数正常词（`不畏强暴`、`乐而不淫`、`列风淫雨` 这类成语被 `强暴`/`淫` 命中）。
在儿童产品里，**宁可少给几个组词**。

## 数学（`public/math/data/`）

由 `tools/math/gen_problems.py` 生成，**没有任何第三方数据**：
题目和答案都是脚本用 Python 算出来的（算不出合法答案的不生成）。

这是数学岛最划算的地方 —— **零授权风险、零内容采购成本**，而且答案不会写错。

## 记一条纪律

**"能下载到"不等于"能用"。** 上面 `ci.json` 那次就是因为只看条数（26 万条）
没看内容性质（古汉语词典），差点把「花国」这种词放进小学生的字表。

新增数据源时至少要确认三件事：
1. **授权**能不能商用（MIT / Apache / CC0 这类）
2. **内容性质**是不是目标用途要的（现代 vs 古文、通用 vs 专业）
3. **抽样看过**真实条目，而不是只看条数和字段名
